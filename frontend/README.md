# Frontend - React 19 + TypeScript + Vite 7 + Tailwind CSS v4

This folder contains the React 19 single-page application.

For complete documentation, tutorial, role setup, and running instructions, refer to the [Root README.md](../README.md).

### Quick Commands

```bash
# Setup
npm install

# Run dev server (http://localhost:5173)
npm run dev

# Type check & production build
npm run build
```
