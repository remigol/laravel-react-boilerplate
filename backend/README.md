# Backend - Laravel 12 API (Clean Architecture)

This folder contains the Clean Architecture Laravel 12 API for the application.

For complete documentation, tutorial, role setup, and running instructions, refer to the [Root README.md](../README.md).

### Quick Commands

```bash
# Setup
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate:fresh --seed

# Run dev server
php artisan serve

# Run test suite
php artisan test
```
